# دليل مراكز التطعيم – ليبيا 🇱🇾

تطبيق PWA لدليل مراكز التطعيم في ليبيا، صادر عن المركز الوطني لمكافحة الأمراض.

## المميزات
- 🏥 دليل شامل لمراكز التطعيم حسب البلدية
- 📅 جدول التطعيمات الوطني الليبي
- 📱 يعمل على الهاتف كتطبيق (PWA)
- 💾 يعمل بدون إنترنت بعد التثبيت
- 🔄 واجهة عربية كاملة

## رابط التطبيق
بعد النشر على GitHub Pages:
`https://USERNAME.github.io/REPO_NAME`

## كيفية النشر على GitHub Pages

1. أنشئ مستودعاً جديداً على GitHub
2. ارفع جميع الملفات
3. اذهب إلى **Settings → Pages**
4. اختر **Source: GitHub Actions**
5. سيتم النشر تلقائياً ✅

## البلديات المتاحة
- بلدية الخمس
- بلدية تاجوراء
- بلدية درنة
- بلدية مصراتة
- (المزيد قريباً)
